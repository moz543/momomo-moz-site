これはサンプルです。本番では実作品の説明をここに書く。

Markdown が使えるので、**強調**、*斜体*、[リンク](https://example.com) 等が普通に書ける。

## 画像を入れる

```mdx
import myImage from '../../assets/works/<your-work>/01.jpg';

<Image src={myImage} alt="説明" />
```

## YouTube / Vimeo を埋め込む

```mdx
<VideoEmbed provider="youtube" id="dQw4w9WgXcQ" />
```

frontmatter に `video` を書いておけば、ヘッダ画像の代わりに動画が出る。
